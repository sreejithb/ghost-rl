  • Mazes cleared: games where Pac-Man ate all 244 dots. Dots left: dots remaining when the game ended. Ticks per game: average game length (the limit is 2,000).
  • *Return uses the default reward: +0.1 per dot, +0.5 extra per power pellet, +1 per ghost eaten, −5 if caught, +10 for clearing, −0.005 per tick. Groups trained on a different reward show a dash, because their returns are in other units.
  • Planners play 100–200 games with 2% random moves, so repeated games differ. RL numbers come from 200 sampled-move games per seed. Greedy (most-likely-move) evaluation is a single repeated game and is left out.
  • With 2 to 3 seeds the RL results are noisy: seeds in one group often differ by more than the gaps between groups. Treat gaps under about 30 dots as noise.
  • Planner and RL runs measured at different times. RL training speed was about 10,000 steps/s on a T4 GPU (laptop CPU: 300–500).
